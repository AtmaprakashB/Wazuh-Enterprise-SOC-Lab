# Discovery

## Overview

Discovery is the post-compromise phase of the attack lifecycle where an attacker gathers detailed information about the compromised Active Directory environment. After obtaining valid credentials and elevated privileges, the attacker enumerates users, computers, groups, network shares, and logged-on sessions to identify valuable assets and prepare for lateral movement.

This simulation demonstrates common Active Directory discovery techniques using NetExec against the Wazuh Enterprise SOC Lab while validating that endpoint telemetry is successfully collected and analyzed through Wazuh and Sysmon.

---

# Objectives

- Enumerate Active Directory users.
- Enumerate domain computers.
- Enumerate Active Directory groups.
- Enumerate accessible SMB shares.
- Enumerate logged-on users.
- Validate endpoint telemetry collection in Wazuh.
- Investigate discovery-related events through Wazuh Threat Hunting.

# Discovery Activities

## 1. Domain User Enumeration

Enumerated Active Directory user accounts through LDAP.

**Purpose**

- Discover valid domain users.
- Identify potential privileged accounts.
- Map the Active Directory environment.

---

## 2. Domain Computer Enumeration

Enumerated all domain-joined systems.

**Purpose**

- Identify servers and workstations.
- Discover potential lateral movement targets.

---

## 3. Domain Group Enumeration

Enumerated Active Directory security groups.

**Purpose**

- Identify privileged groups.
- Discover administrative memberships.
- Understand Active Directory permissions.

---

## 4. SMB Share Enumeration

Enumerated SMB shares available within the domain.

**Purpose**

- Identify accessible shared resources.
- Locate potentially sensitive data.
- Discover administrative shares.

---

## 5. Logged-on User Enumeration

Enumerated currently logged-on users.

**Purpose**

- Identify active user sessions.
- Discover privileged user activity.
- Identify potential impersonation or lateral movement targets.

# Wazuh Detection

Following execution of the discovery commands, Wazuh successfully collected endpoint telemetry generated by Sysmon on the monitored Windows endpoint.

Observed telemetry included:

- Windows process creation events.
- Sysmon Event ID 1 detections.
- Discovery-related process execution.
- Remote Desktop session enumeration detection.
- Threat Hunting event correlation.

---

# Detection Analysis

The Wazuh detection rule successfully identified execution of **qwinsta**, a Windows utility commonly used to enumerate Remote Desktop sessions and logged-on users.

**Detected Rule**

- Rule ID: **92022**
- Rule Description: **Gathered user information from Remote Desktop Service sessions**

**MITRE ATT&CK**

- Tactic: **Discovery**
- Technique: **System Owner/User Discovery (T1033)**

This demonstrates Wazuh's ability to identify common post-compromise discovery behavior through Sysmon process monitoring.
