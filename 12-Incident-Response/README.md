# 01 – Alert Identification

## Overview

Alert identification is the first phase of the incident response lifecycle where security alerts are reviewed to identify potentially suspicious activity requiring further investigation.

This investigation was performed against the Wazuh Enterprise SOC Lab using Wazuh Discover. The objective was to identify security alerts generated by the `WINTERFELL` Windows endpoint, review the associated Wazuh detection rule, and collect the initial evidence required for incident investigation.

---

# Objectives

- Identify security alerts generated by Wazuh.
- Filter alerts associated with the `WINTERFELL` endpoint.
- Identify the Wazuh detection rule associated with an alert.
- Review the alert description and severity level.
- Review the MITRE ATT&CK mapping.
- Identify the affected endpoint and event timestamp.
- Collect initial evidence for incident response.
